# Vendored fonts

Bundled so the resume builds identically anywhere, with no system font
installation. Both are Adobe typefaces under the SIL Open Font License 1.1
(see `OFL.txt`).

| Font | Version | Used for |
| --- | --- | --- |
| Source Sans Pro | 2.045R-ro / 1.095R-it | All body text (matches the original LaTeX `sourcesanspro` package) |
| Source Code Pro | 2.042R-u / 1.062R-i | Inline `#code[...]` spans |

Upstream: <https://github.com/adobe-fonts/source-sans> ·
<https://github.com/adobe-fonts/source-code-pro>
